# Eventers – home of exclusive events

Alvin's offline event planner (English and Kiswahili): checklist with ready-made templates, budget, vendors, michango (pledges and payments), guests with door check-in, and the programme of the day.

Plain HTML, CSS and JavaScript, no build step. Data stays on the phone (localStorage); More › Save a backup downloads a copy.

Live at https://nathankagoro.github.io/sherehe/ (GitHub Pages from `main`, root folder). When you change files, bump `CACHE` in `sw.js` so installed phones pick up the new version.
